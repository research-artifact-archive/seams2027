# Historical evidence descriptors

These unchanged descriptors, outcome summaries, qualification records, and bibliography entries bind the scientific archives and the recorded checks. Their embedded repository paths and collection counts describe the original evidence releases, before the current layout.

Use [the current evidence index](../EVIDENCE_INDEX.json) and [archive catalogue](../archives/README.md) to locate files now. Use [reproduce/MANIFEST.json](../../reproduce/MANIFEST.json) and its [verifier](../../reproduce/README.md) for the current complete distribution. Inner ZIP member paths and scientific payloads are unchanged.

The complete old distribution manifests and validators remain at [their fixed versions](../../docs/versions.md).
