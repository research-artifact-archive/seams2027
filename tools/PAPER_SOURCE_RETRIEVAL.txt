Published specification sources: retrieval and byte reconstruction

The saved evidence uses specifications from arXiv:2609.12231v1. The public
evidence package does not redistribute those third-party specification
listings or their reconstructed copies. This helper retrieves the public
versioned HTML directly from arXiv and extracts its downloadable plain-text
listing payloads. The source and its terms remain those of the original
publisher; this repository does not grant a new license to third-party text.

Requirements: Python 3.9 or later, standard library only. The online mode uses
one HTTPS GET, with a 30-second timeout and a 5 MB response limit. No native
runtime, synthesis engine, model, controller, or scientific checker is run.

Inspect/reconstruct in memory without writing source files:

  python3 fetch_paper_sources.py --check-only

Restore omitted files after extracting the public evidence archives into a
shared directory:

  python3 fetch_paper_sources.py --output-root ./extracted-evidence

The output directory must contain, or be intended to contain, the original
archive directories seams2027-saved-evidence and
seams2027-lift-direct-static-evidence. The manifest records full relative
archive member names. The helper writes only missing source/diff files and
refuses to replace an existing file whose bytes differ.

To inspect the complete 16-listing population in a separate directory:

  python3 fetch_paper_sources.py --canonical-dir ./retrieved-sources

This produces raw/, reconstructed/, diffs/, and the common response-pattern
source under sources/. For an already obtained copy of the versioned HTML,
append "--html /path/to/2609.12231v1.html"; that mode makes no network request.

Binding and scope:

* The 16 listings are five original, five preferred, and six trivial
  specifications. The eleven replacements retain their original population.
* Each source is selected by its exact HTML listing ID. Its base64 payload
  must match the saved raw-source byte count and SHA-256.
* The response-pattern body is taken from the original Arbiter listing, not
  supplied by this helper. The saved pattern byte count and SHA-256 must match.
* The declared changes are twelve appends of that omitted pattern, two
  spelling reconstructions, and one response-formula lowering. They preserve
  the historical distinctions between raw and reconstructed inputs. An
  undefined raw call is not claimed to have the reconstructed semantics.
* All 16 raw, reconstructed, and unified-diff hashes, plus the response-pattern
  hash, are checked before any source file is written.
* The manifest covers 87 source/diff copies in the historical archives:
  85 in saved evidence and two in the direct Lift static evidence. The
  verification addendum contains no copies from these arXiv listings.
* Each restored archive member has exactly its historical bytes. Fetching
  them does not rerun or extend a scientific result or validate a native
  toolchain. Historical evidence limitations continue to apply.

The full HTML hash is reported for provenance but is not required to match,
because publisher wrappers can change without changing the pinned listing
payloads. Any changed source payload, reconstruction, or diff fails closed.
If the service or payload becomes unavailable, provide a previously obtained
v1 HTML file; do not substitute another version or change the expected hashes.

Files to distribute:
