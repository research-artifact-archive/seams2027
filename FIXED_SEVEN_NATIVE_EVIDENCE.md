# Fixed-seven native saved-data evidence

This immutable snapshot compares the original and selected released syntactic route on seven previously eligible cooperative-positive public inputs. The selection used already known cooperative initialization and a carrier limit of 65,536. Old symbolic W=K and literal-model preservation were already known. This is a disclosed positive/control study, not a blind search or prevalence estimate.

Download [the archive](archives/fixed-seven-native-evidence-20261024-v1.zip) (SHA-256 `33d33874d0c4dd7c6c095456387b51147959aa001b258ffbe6490f18bf648fe3`), unpack it, and read `fixed-seven-native/README.txt`. Run `python3 -B replay.py --output ../replay-output` inside that directory with Python 3.9 or later on POSIX. It requires only the standard library. The output directory must be new and outside the payload. The seven saved-data workers each have a 120-second wall cap and 1 GiB RSS cap; aggregate output is capped at 1 GiB. First failure stops the remaining cases without retry.

The unchanged independent mathematical core checks field/AUX domains and named value encodings, original predicates and ordered justices, source-view correspondence, all typed memberships and initialization witnesses. This evaluates saved evidence; it does not regenerate native solves or independently establish compiler/solver correctness. Source/parser exports and encoding metadata remain shared dependencies.
