# Versions and citations

## Maintained entry point and fixed evidence

The [repository URL](https://github.com/research-artifact-archive/seams2027) is the maintained entry point for readers. It can evolve as navigation improves. The immutable [`reader-layout-20261024-v1` snapshot](https://github.com/research-artifact-archive/seams2027/tree/reader-layout-20261024-v1) fixes this purpose-based layout and the v70-r1 paper/source snapshot.

For a scientific claim, use the evidence tag cited by the paper and the archive/member named in the [evidence index](../results/EVIDENCE_INDEX.json). Each scientific ZIP under [results/archives/](../results/archives/README.md) retains its original bytes. Relocating the outer ZIP does not change its internal member names or the files reached through an older fixed-tag URL.

The paper therefore cites the maintained repository for discovery and fixed evidence versions for reproducibility. [paper/PAPER_MANIFEST.json](../paper/PAPER_MANIFEST.json) binds the current main PDF, supplement, and source ZIP; [reproduce/MANIFEST.json](../reproduce/MANIFEST.json) binds the complete current file set. Publication here records an artifact version, not conference acceptance.
